# One Page Web App

This is a simple one-page web application designed to replicate the layout and functionality of the referenced product design. The app includes a digital clock, a task scheduler, and interactive buttons.

## Demo

You can access the live version of the app here:
[One Page Web App on GitHub Pages](https://ARadwan97.github.io/one-page-web-app/)

## Features

- **Digital Clock**: Displays the current time, date, and additional details like weather.
- **Interactive Buttons**: Various buttons for navigation and interaction.
- **Task Scheduler**: Lists tasks, each with a time slot and a completion button.
- **Responsive Design**: Adjusts to different screen sizes.

## Technologies Used

- **HTML**: Structure of the web app.
- **CSS**: Styling for the layout and components.
- **JavaScript**: Logic for dynamic features like the clock and task completion.

## How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/ARadwan97/one-page-web-app.git
   cd one-page-web-app
   ```
2. Open the `index.html` file in a web browser.
